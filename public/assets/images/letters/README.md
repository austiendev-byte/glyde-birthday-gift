# Letter photos (Section 03)

| File | Where it appears | Shape | Recommended size |
|---|---|---|---|
| `letter-photo-1.jpg` | Polaroid beside the letter | Portrait 4:5 | 900 × 1125 px |
| `letter-photo-2.jpg` | Small framed photo by the signature | Square 1:1 | 600 × 600 px |

Pick quiet, intimate photos. They sit beside the words, so calm images work best.
Different filename? Change it in `src/config/photos.js` → `letters`.
