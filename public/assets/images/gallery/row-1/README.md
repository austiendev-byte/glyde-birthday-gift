# Gallery row 1 (Section 02, moves right → left)

Name your photos `memory-01.jpg` … `memory-07.jpg`, or list your own filenames in
`src/config/photos.js` → `gallery.row1`. You can add or remove entries.

- Mix shapes for an editorial look: portrait 4:5 and 3:4, square 1:1, landscape 3:2 and 4:3.
  Set each photo's `aspect` in the config to match.
- Photos are shown about 300 px tall on desktop, so 900 px on the long side is plenty.
- JPG or WebP, under ~300 KB each.
- Optional `caption` adds a small handwritten-style label (keep it to 1–3 words).
