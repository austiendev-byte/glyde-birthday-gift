# Gallery row 2 (Section 02, moves left → right)

Name your photos `memory-08.jpg` … `memory-14.jpg`, or list your own filenames in
`src/config/photos.js` → `gallery.row2`. You can add or remove entries.

- Mix shapes: portrait 4:5 and 3:4, square 1:1, landscape 3:2 and 4:3.
  Set each photo's `aspect` in the config to match.
- About 900 px on the long side, JPG or WebP, under ~300 KB each.
- Try not to repeat row 1's photos so the two rows feel different.
