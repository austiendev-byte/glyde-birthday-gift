# Background music

Place your copy of **"Panaginip"** here as `panaginip.mp3`.

- Use a recording you bought or have permission to use.
- MP3 at 128–192 kbps keeps the file small (about 3–5 MB).
- Set the title and artist, or a different filename, in `src/config/music.js`.

If this file is missing, the music button stays hidden and everything else still works.
